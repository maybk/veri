# 构建与打包配置 (`build`)

管理应用元信息配置、跨平台编译引擎与各目标系统归档任务。

## 目录结构

- `config.yml`：应用元信息与版本号配置。
- `Taskfile.yml`：跨平台静态编译、归档打包与校验和共用任务。
- `darwin/`：macOS（`arm64` / `amd64`）独立构建与 `.tar.gz` 打包任务。
- `linux/`：Linux（`arm64` / `amd64`）独立构建与 `.tar.gz` 打包任务。
- `windows/`：Windows（`arm64` / `amd64`）独立构建与 `.zip` 打包任务。

## 开发规范

- **职责分离**：本目录仅维护构建配置与打包任务，不放置 Go 源码文件。
