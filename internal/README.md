# 内部模块 (`internal`)

承载联网检索与网页提取领域模型、安全网络客户端、多源适配器、路由编排、配置管理以及 CLI 与 MCP 服务端实现。

## 目录结构

- `spec/`：全局静态规格、应用身份、内置 Provider 注册表、跨包扩展选项键与共享默认阈值。
- `mdscan/`：零依赖 Markdown 行级结构识别（围栏代码块状态机与 ATX 标题解析）。
- `textnorm/`：文本清洗、隐形注入字符剥离、多格式宽容时间解析与网页正文三级质量闸门。
- `core/`：核心领域模型、统一输出信封、正交适配器接口、整数微单位成本、日历时间窗与标准错误码。
- `urlnorm/`：URL 规范化、追踪参数剥离与多源融合去重键生成。
- `keypool/`：同厂商多密钥轮询、按状态分级退避冷却与失效隔离。
- `htmlmd/`：纯 Go HTML DOM 预处理与紧凑 GFM Markdown 渲染。
- `httpx/`：SSRF 拨号防护、透明代理 TUN Fake-IP 放行、解压体积限制、并发闸门与计费安全重试客户端。
- `provider/`：各上游检索源与本地/GitHub 网页正文提取器的正交实现集合。
- `router/`：链式故障回退、并发 RRF 融合、正文质量闸门升档、过滤条件模拟与字符预算裁剪。
- `config/`：`~/.config/veri/` 配置加载、TOML 未知键拦截与三级凭据合并。
- `app/`：显式 Provider 注册装配、CLI 磁盘缓存、MCP 进程内内存缓存、并发请求合并与健康诊断。
- `update/`：官方 GitHub Releases 版本检查、SHA-256 校验、安装形态识别与跨平台原子自更新引擎。
- `render/`：检索结果与网页正文的 Markdown / JSON / JSONL / URL 渲染及外部内容标签包裹。
- `cli/`：Cobra 命令行入口、双语词表与全仓架构合规测试。
- `mcpserver/`：基于官方 MCP Go SDK 的 stdio 服务端与输入/输出 Schema。

## 开发规范

- **分层单向依赖**：严格遵守自底向上的导入边界，禁止循环依赖或跨层逆向导入。
- **网络与凭据边界**：所有外部请求统一经由 `internal/httpx`；配置展示、运行日志与错误提示在输出前统一遮蔽敏感凭据。
