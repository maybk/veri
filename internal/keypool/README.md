# 多密钥轮询与冷却池 (`internal/keypool`)

管理同一上游厂商的多把 API Key 并发安全轮询、按错误类型分级退避冷却与耗尽原因诊断。

## 目录结构

- `keypool.go`：原子游标轮询取键、`429` 指数退避冷却（优先遵循 `Retry-After`）、`402` 余额耗尽隔离、`401` 鉴权失败长冷却隔离及耗尽原因诊断（`DiagnoseExhaustion`）。

## 开发规范

- **零外部依赖**：仅依赖 Go 标准库，通过可注入时钟支持无休眠确定性单元测试。
- **密钥隔离**：内部仅按槽位索引与冷却状态调度，对外诊断仅返回原因枚举，不向日志或错误暴露明文密钥。

## 验证
