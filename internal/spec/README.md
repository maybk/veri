# 全局静态规格与注册表 (`internal/spec`)

集中维护应用身份标识、内置 Provider 注册表、跨包扩展选项键与共享默认阈值常量。

## 目录结构

- `doc.go`：包级说明与依赖边界。
- `app.go`：应用名称、Schema 版本、配置文件名、内嵌资产路径、输出格式与 MCP 工具标识常量。
- `registry.go`：内置 Provider 单表登记（`Providers()` / `Role`）、上游默认端点、认证请求头、环境变量映射与默认路由链查询。
- `options.go`：跨包共享的厂商运行模式枚举与按次扩展参数键常量。
- `defaults.go`：跨包共享的默认条数、并发、字节上限、Fake-IP 网段与超时预算常量。

## 开发规范

- **零外部依赖**：仅允许导入 Go 标准库，严禁引入任何第三方库或仓库内其他子包。
- **最小作用域控制**：仅收纳多包共享的契约常量与默认边界，单模块内部调优参数保留在各自包内维护。
