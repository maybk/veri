# 项目指南 (`docs/guide`)

维护面向用户与开发者的长期稳定指南文档。

## 目录结构

- `usage.md`：日常使用指南、各源 API Key 官方申请入口、常用命令、AI Agent 接入与升级排查。
- `overview.md`：整体架构、模块职责边界与目录结构。
- `configuration.md`：配置目录、合并优先级、TOML 字段、环境变量与安全机制。
- `providers.md`：内置检索与提取适配器能力矩阵、选路模式与扩展选项。
- `development.md`：开发环境、本地构建、测试命令、代码规范与交付检查。
- `release.md`：版本号管理、Rolling 预发布与正式版本发布流程。

## 维护规范

- **独立自洽**：指南仅描述已落地的稳定设计与对外行为，不写入临时排错记录。
- **同步更新**：修改配置字段、命令参数、适配器或发布产物时，同步更新对应指南。
